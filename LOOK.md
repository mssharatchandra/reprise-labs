# LOOK.md — Reprise

Warm, readable, professional. A desk someone would sit at, not a poster and not a theme.

## Color

- Room `#F3EBDD`
- Sheet `#FFF9F1`
- Ink `#2A2420`
- Pencil `#7C736A`
- Rule `#E6D9C8`
- Mark `#C46A45` — soft copper. The selected person, the call, a received payment. Never a big filled button.

## Type

- Names: Fraunces 32px. Wordmark 26px.
- Body: 16px, line height 26px. Labels 13px pencil, always above the value, never hidden.
- Amounts: 16px tabular, same color as ink, right aligned.

## Layout

Masthead, then one quiet status line. Queue on the left with 20px between rows so names do not touch. Open case on a warm sheet with real labels: What happened, Last tries, Next. The action is a sentence, “Call the test number”, with the copper mark. Checkout is the same sheet, amount large, “Pay” as text, receipt on its own line.
